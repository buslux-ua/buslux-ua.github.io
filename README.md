# BusLux

Сайт компанії BusLux — пасажирські перевезення Україна — Європа.

Статичний сайт (HTML + CSS + JS), без збірки. Публікується через GitHub Pages.

- `index.html` — розмітка та українські тексти
- `css/style.css` — стилі
- `js/i18n.js` — переклади (RU, EN)
- `js/main.js` — галерея, карта, форма бронювання, меню, тема, WhatsApp
- `js/prices.js` — **ціни маршрутів** (євро, Comfort / Lux) і курс НБУ. Щоб змінити ціну — поміняйте число в цьому файлі; гривні рахуються автоматично. Щоб оновити курс — змініть `rate` і `rateDate`.

WhatsApp менеджера: номер задається в `js/main.js` (`WA_NUMBER`) та в посиланнях `wa.me/380937710944` в `index.html`.

Telegram менеджера задається в `js/main.js` (змінна `MANAGER`) та в посиланнях `t.me/manager_bus_lux` в `index.html`.

Фото — ілюстративні, з Unsplash (вільна ліцензія). Рекомендується замінити на реальні фото автопарку.
